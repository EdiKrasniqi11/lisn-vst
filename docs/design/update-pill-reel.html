Update pill + name reel

How 0.3.0 places the update pill next to the StemSplitter / Harmonies reel (Header::placeUpdate). Click the name or the buttons to spin it, and pick a pill text.

Desktop app (title bar)

There's no room for both, so the pill takes the name's place right after "LISN" while the reel rests on StemSplitter. When the reel spins, or shows Harmonies, the pill steps aside and the name comes back. (On StemSplitter, Harmonies is reached with the choir icon.)

FL Studio / Ableton plugin (header)

The plugin has no window buttons, so there's room: the pill always sits after the name, on StemSplitter and Harmonies alike, and stays put while the reel spins. If the long text would run into the theme pill, it switches to the short one ("Restart FL Studio to finish" → "Restart to finish").
